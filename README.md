PDF ANSWERING CHATBOT

A simple chatbot that reads a PDF file and answers questions based only on the PDF content.

Features:

-Upload a PDF file
-Ask questions about the PDF
-Shows relevant content from the PDF
-Says “Content not found” if the answer is not in the PDF
-Technologies Used

Python:

-LangChain
-FAISS
-Sentence Transformers
-Transformers (FLAN-T5)
-PyPDF2

How to Run:

Open the notebook in Google Colab or Jupyter Notebook
Upload a PDF file
Run all cells

Ask questions in the input prompt

Type exit to stop
